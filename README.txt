GitHub Pages:
1. Create a public repository named hemant-professional-portfolio.
2. Upload index.html and the entire assets folder, preserving the folder structure.
3. Go to Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for deployment and open the Pages URL.
6. Test every download link and check the site in a private browser window.
7. Submit the public website URL in Brightspace. index.html itself is not the submission link.
